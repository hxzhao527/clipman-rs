# clipman-rs MVP 需求与交互规范

> 状态：需求基线已对齐  
> 日期：2026-10-27  
> 目标：在 labwc/Wayland 环境中提供一个类似 `xfce4-clipman-plugin` 的独立剪贴板历史管理器。

## 1. 背景与目标

用户从 Xfce 切换到 labwc 和 Waybar 后，不再使用 `xfce4-panel` 中的 `xfce4-clipman-plugin`。`wl-clipboard` 这类命令行工具无法提供方便的历史浏览和托盘交互，因此需要一个独立运行、通过系统托盘访问的剪贴板管理器。

首版重点是稳定地完成文本剪贴板历史、系统托盘菜单、可搜索的历史窗口和持久化，不追求完整复刻 `xfce4-clipman-plugin` 的全部功能。

## 2. 目标环境

- 桌面环境使用 labwc/Wayland。
- XWayland 已安装。
- 程序不主动依赖 XWayland；通过 XWayland 提供的剪贴板内容应尽可能由 compositor 的桥接机制兼容。
- 系统托盘采用通用 StatusNotifierItem 方式，不绑定 Waybar。
- Waybar 通过自带的 tray 模块显示托盘图标，不使用专用的 Waybar 自定义模块。
- 程序是否随桌面会话自动启动由桌面配置管理，程序本身不负责安装或管理 autostart 项。
- 程序必须单实例运行，重复启动时不能创建第二个监听器、托盘图标或历史数据写入者。
- 重复启动程序时，已有实例打开“展示全部记录”窗口。
- 程序启动时只加载持久化历史，不自动把上一次的历史内容写回系统剪贴板。
- 用户界面需要支持国际化（i18n），用户可见文本不能硬编码在业务逻辑中。
- MVP 提供简体中文和英文，并根据系统 locale 选择语言。

## 3. MVP 功能范围

### 3.1 文本内容判定

一条剪贴板事件只有在明确提供基础媒体类型 `text/plain` 时才记录。

- `text/plain;charset=UTF-8` 等带参数的类型也视为提供了 `text/plain`。
- 如果没有 `text/plain`，即使存在 `text/html` 或 `text/uri-list`，也不记录该条内容。
- 程序不通过内容嗅探判断是否属于文本。
- 对 `text/plain` 的首尾空白字符进行 trim 后，如果内容为空，则不记录该条内容。
- 空白字符包括空格、回车、换行、制表符等 Unicode 空白字符。
- trim 仅用于空内容判定和界面预览，不改变保存和恢复的原始内容。

满足记录条件时：

- 同一次剪贴板事件中提供的所有 `text/*` 表示都保存到同一个历史条目。
- 保留原始 MIME 类型、MIME 参数和对应的内容。
- 例如同时提供 `text/plain`、`text/html` 和 `text/rtf` 时，三者全部保存。
- 历史列表的预览直接使用 `text/plain`，不从其他 MIME 生成预览。
- 恢复条目时，将保存的完整 `text/*` MIME 集合重新提供给系统剪贴板。
- 目标应用根据自身规则和用户使用的粘贴快捷键选择具体 MIME 表示。
- 程序不负责决定普通粘贴和纯文本粘贴分别使用哪种格式，也不进行 HTML 到纯文本等转换。
- 如果 `text/plain` 读取失败，则不记录该条内容。
- 如果 `text/plain` 读取成功，但其他某个 `text/*` 表示读取失败或超时，则忽略该失败表示，并使用成功读取的内容创建记录。
- 读取失败的其他 MIME 表示不生成占位内容。
- 一条记录中所有成功读取的 `text/*` 表示合计大小上限为 4 MiB（4 × 1024 × 1024 字节）。
- 如果合计大小超过 4 MiB，则整条记录跳过，不进行截断。
- 该大小上限不作为用户配置项。

### 3.2 普通剪贴板历史

- 普通历史按最近使用时间倒序排列。
- 普通历史保存文本和完整的 `text/*` 表示集合。
- 文本成功捕获后，即使源应用随后退出，普通剪贴板内容仍应保持可粘贴，不要求用户重新从历史中选择。
- 用户选择某条普通历史后，该条目移动到普通历史顶部。
- 普通历史最大存储数量可配置。
- 托盘菜单最多展示的普通历史数量可配置。
- 两个数量必须满足：

```text
1 <= 菜单最大展示数 <= 最大存储记录数
```

- 默认最大存储记录数为 20，默认菜单最大展示数为 10。
- Primary Selection 内容不计入这两个数量。
- 用户调小最大存储记录数时，立即保留当前顺序中最新的指定数量记录，并丢弃其余较旧的普通历史。
- 调整最大记录数导致的淘汰不显示确认窗口，Primary Selection 不受影响。

### 3.3 重复内容

- 如果完整 `text/*` 表示集合相同，即 MIME 类型和内容均相同，则不创建重复记录。
- 再次复制相同内容时，将已有记录移动到普通历史顶部。
- `text/plain` 内容相同，但保存的 `text/*` MIME 集合不同，则视为不同记录。
- 从历史恢复内容时，不创建内容重复的新记录。

### 3.4 自身写入剪贴板的事件抑制

用户从历史中选择条目时，程序需要把内容写入普通剪贴板。此后 compositor 可能因为程序自身的写入而产生新的剪贴板变化事件，该事件不得再次触发历史记录处理。

具体要求：

- 点击历史条目后，条目只移动到普通历史顶部一次。
- 程序写入剪贴板后由自身引起的事件必须被忽略。
- 该事件不得新增记录、不得再次调整顺序、不得再次写入持久化存储。
- 事件抑制只针对本次程序自身写入，不能将对应内容永久加入忽略列表。
- 用户之后从其他应用再次复制相同内容时，仍应按照重复内容规则正常处理，并移动到顶部。

### 3.5 Primary Selection

- Primary Selection 默认开启。
- 开启时监听 Primary Selection，只保留最近一条。
- Primary 内容单独显示在托盘菜单顶部，不计入普通历史数量和菜单展示数量。
- 开启功能时不主动读取当前已有的 Primary Selection，只等待后续 Primary Selection 变化。
- 关闭功能时停止监听并清除已保存的 Primary 记录。
- 再次开启后等待下一次 Primary Selection 变化，不恢复关闭前的旧记录。
- Primary 内容同样适用 `text/plain` 判定规则。
- 点击托盘菜单顶部的 Primary 内容时，将它的完整 MIME 集合写入普通剪贴板。
- Primary 内容不出现在“展示全部记录”窗口中。

## 4. 系统托盘与菜单

### 4.1 菜单结构

点击托盘图标后显示菜单，结构如下：

```text
Primary Selection 内容
--------------------
最近 N 条普通历史
--------------------
展示全部记录
清空历史
配置
退出
```

其中：

- Primary Selection 内容仅在功能开启且存在内容时显示。
- Primary Selection 内容与普通历史之间显示分割线；该分割线只在 Primary 内容实际显示时出现。
- `N` 是配置的菜单最大展示数。
- Primary Selection 不占用普通历史的 `N` 个位置。
- Primary Selection 和普通历史条目在菜单中展示 `text/plain` 预览时，先移除内容中的所有空白字符，包括首尾和内部的空格、换行、制表符等。
- 移除空白字符后，预览最多展示前 15 个 Unicode grapheme cluster，内容超出时显示省略号。
- 空白移除和截断只影响托盘菜单预览，不改变保存、搜索或恢复的原始内容。
- 菜单预览长度限制属于显示层参数，不加入配置窗口；开发时可根据 Waybar 中的实际显示效果调整。
- 没有历史内容时，控制项仍然显示。

### 4.2 菜单中的历史选择

从托盘菜单点击 Primary 内容或普通历史条目时：

1. 将条目的完整 MIME 集合写入普通剪贴板。
2. 将普通历史条目移动到普通历史顶部。
3. 托盘菜单关闭。

程序不模拟 `Ctrl+V`，也不自动切换或点击目标应用。用户自行切换到目标应用并执行粘贴。

单条记录删除只在“展示全部记录”窗口中提供，不在托盘菜单中提供。

## 5. “展示全部记录”窗口

### 5.1 展示和搜索

从托盘菜单点击“展示全部记录”后，打开独立窗口：

- 只展示普通历史，不展示 Primary Selection。
- 顶部提供搜索框。
- 搜索对 `text/plain` 内容执行不区分大小写的包含匹配。
- 搜索结果按当前普通历史顺序展示。
- 列表支持滚动。
- 可展示最大存储记录数允许的全部普通历史。

### 5.2 窗口中的条目操作

从窗口点击条目时：

1. 将条目的完整 MIME 集合写入普通剪贴板。
2. 将该条目移动到列表顶部。
3. 窗口保持打开。

用户可以继续浏览、搜索或手动关闭窗口。由于窗口不会自动关闭，焦点仍可能留在管理器中，用户需要自行切换到目标应用执行粘贴。

窗口还需要提供单条记录删除功能：

- 鼠标悬停在记录条目上时，在该行末尾显示“叉号”删除按钮；
- 点击叉号后直接删除对应记录，不弹出额外确认窗口；
- 删除只影响对应的普通历史记录；
- 删除后立即持久化；
- 托盘菜单不提供单条删除操作。

### 5.3 窗口中的清空历史

- 条目列表下方提供“清空历史”按钮。
- 点击后弹出确认窗口。
- 确认后清空全部普通历史，而不只是当前搜索结果。

## 6. 清空历史

MVP 有两个“清空历史”入口，作用范围一致，都只清除普通历史：

### 6.1 托盘菜单入口

- 点击后立即执行，不显示确认窗口。
- 清空全部普通历史。

### 6.2 全部记录窗口入口

- 点击后显示确认窗口。
- 用户确认后清空全部普通历史。

Primary Selection 通过关闭 Primary Selection 开关清除，不参与普通历史的清空操作。

两个“清空历史”入口还必须在清空普通历史后清除当前普通剪贴板：

- 清空完成后执行 `Ctrl+V` 不应再取得已清除的内容；
- Primary Selection 不受普通历史清空影响；
- selection cleared 事件不能重新创建历史记录。

## 7. 配置窗口

配置窗口只包含以下设置：

1. 是否记录 Primary Selection。
2. 最大存储记录数。
3. 托盘菜单最大展示数。

配置要求：

- Primary Selection 默认开启。
- 菜单最大展示数不能大于最大存储记录数。
- 默认最大存储记录数为 20，默认菜单最大展示数为 10。
- 不展示缓存目录。
- 不提供自动启动设置。
- 配置变更立即生效并持久化。
- 配置窗口不提供“应用”或“取消”按钮。

## 8. 退出

- “退出”只结束程序进程。
- 退出不清理普通历史。
- 退出不清理 Primary 记录。
- 退出不修改配置。
- 退出后程序不再提供剪贴板数据源。
- 如果退出前普通剪贴板内容由本程序提供，退出后再次执行 `Ctrl+V` 将无法取得该内容。
- 下次桌面会话是否自动启动程序由 labwc 的桌面配置决定。

## 9. 持久化

以下数据需要持久化：

- 普通剪贴板历史；
- 每条普通历史的完整 `text/*` 表示；
- 普通历史的当前顺序；
- 最近一条 Primary Selection；
- Primary Selection 开关状态；
- 最大存储记录数；
- 托盘菜单最大展示数。

持久化要求：

- 新增记录、调整顺序和修改配置后，应尽快写入持久化存储，降低关机或异常退出造成的数据丢失风险。
- 程序启动后加载已保存的历史和配置。
- 持久化实现和存储格式在技术选型阶段确定。

## 10. 非目标

以下内容不属于当前 MVP：

- 图片和截图图片内容的记录、预览及恢复；
- 独立文件对象的复制和恢复；
- `application/*` 等非 `text/*` 格式的保存；
- 收藏、固定条目或 Pin；
- 暂停记录或隐私模式；
- 按时长自动过期的历史清理；
- 自动粘贴或模拟键盘输入；
- 全局快捷键；
- 专用 Waybar 模块；
- 管理桌面自动启动项；
- 按源应用排除剪贴板内容；
- 在配置窗口展示缓存目录。

说明：

- 文件对象本身没有统一的“文件对象 MIME”。
- 复制文件时，剪贴板可能提供 `text/uri-list`，它是 URI 文本表示，不是文件对象本身。
- 按当前规则，只有同一次剪贴板事件还存在 `text/plain` 时，`text/uri-list` 才会随其他 `text/*` 内容一起保存。
- 保存 `text/uri-list` 不代表支持读取、复制或恢复文件对象。

## 11. 验收场景

1. 从应用复制普通文本后，托盘菜单中出现对应历史条目。
2. 从程序 A 复制文本并关闭程序 A 后，程序 B 无需打开 clipman-rs 菜单即可直接粘贴该文本。
3. 从应用复制内容后，如果 `text/plain` trim 首尾空白后为空，则该内容不进入历史。
4. 普通历史条目在菜单中的预览去除了 `text/plain` 的首尾空白，但恢复时仍保留原始内容。
5. 从应用复制同时提供 `text/plain` 和 `text/html` 的内容后，一个历史条目中同时保存两种表示。
6. 只提供 `text/html`、不提供 `text/plain` 的内容不进入历史。
7. `text/plain` 读取失败时不创建记录；其他 `text/*` 读取失败时，使用成功读取的表示创建记录。
8. 一条记录的所有 `text/*` 合计超过 4 MiB 时，整条记录不进入历史，也不发生截断。
9. 菜单中的 Primary 和普通历史预览移除全部空白字符，再最多展示前 15 个 grapheme cluster；超出部分以省略号表示。
10. 从托盘菜单选择历史条目后，内容进入普通剪贴板，菜单关闭，条目移动到顶部。
11. 从“展示全部记录”窗口选择条目后，内容进入普通剪贴板，条目移动到顶部，窗口保持打开。
12. 鼠标悬停在“展示全部记录”窗口的条目上时，行尾显示叉号按钮；点击后直接删除该记录并持久化。
13. 普通历史达到最大存储记录数后，不再无限增长。
14. 调小最大存储记录数后，立即删除超出数量且较旧的普通历史。
15. 托盘菜单最多展示配置数量的普通历史，“展示全部记录”窗口可以展示全部已保存普通历史。
16. 从历史选择内容后，程序自身写入剪贴板所产生的事件不会新增记录或再次触发排序。
17. 自身写入事件被抑制后，用户从其他应用再次复制相同内容仍会正常记录或移动到顶部。
18. Primary Selection 开启时，最近一次变化显示在托盘菜单顶部，并且不出现在“展示全部记录”窗口。
19. Primary Selection 内容实际显示时，其与普通历史之间存在分割线；未显示 Primary 内容时不添加该分割线。
20. 关闭 Primary Selection 开关后，对应记录被清除，且不再继续监听。
21. 托盘菜单中的“清空历史”不确认就清空普通历史，同时清除当前普通剪贴板。
22. 全部记录窗口中的“清空历史”需要确认后才清空普通历史，同时清除当前普通剪贴板。
23. 配置窗口中的开关或数值修改后立即生效并保存，不需要额外的应用操作。
24. 重复启动程序不会创建第二个实例，也不会产生第二个监听器或托盘图标；已有实例打开“展示全部记录”窗口。
25. 重启程序后，普通历史、顺序、Primary 记录和配置仍然存在。
26. 程序启动时只加载历史，不自动将上一次的剪贴板内容写回系统剪贴板。
27. 从历史选择内容并退出程序后，如果普通剪贴板内容由本程序提供，再次执行 `Ctrl+V` 将无法取得该内容。
28. 点击“退出”后程序停止运行，但历史、顺序、Primary 记录和配置不被清理。
29. MVP 的界面文案支持简体中文和英文，并根据系统 locale 选择语言。

## 12. 技术选型前需要验证的风险

需求确认后，技术选型阶段优先验证以下能力：

1. labwc/Wayland 下监听普通剪贴板和 Primary Selection 的变化。
2. 读取同一次剪贴板事件中的全部 `text/*` 表示。
3. 在恢复历史时，作为数据源同时提供多个 MIME 表示。
4. 可靠识别并抑制程序自身恢复剪贴板所产生的事件，同时不影响其他应用后续复制相同内容。
5. 确保程序退出后，由程序持有的剪贴板数据源按预期失效，不承诺继续提供内容。
6. 实现单实例机制，避免重复监听、重复托盘图标和并发写入历史。
7. 在 Waybar 的通用 tray 模块中实现 StatusNotifierItem 图标、动态菜单和菜单动作。
8. 在 Wayland 下打开托盘菜单、搜索窗口和配置窗口，并保持预期的焦点行为。
9. 用所选界面框架实现 i18n，覆盖菜单、窗口、配置项、确认窗口和状态文本。
10. XWayland 应用与 Wayland 应用之间的文本剪贴板内容可以通过 compositor 桥接正常记录和恢复。

这些问题属于技术可行性验证，不改变当前需求基线。
